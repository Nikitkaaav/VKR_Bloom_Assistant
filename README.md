# Интеллектуальная система поддержки проектирования планируемых результатов обучения

## Назначение системы
Система предназначена для методической и грамматической поддержки преподавателей и методистов при формулировании планируемых результатов обучения (ПРО) на основе таксономии Блума.

## Основные функциональные требования
- Интерактивное конструирование ПРО по 6 уровням таксономии Блума.
- Интеллектуальная поддержка ввода: автодополнение глаголов, подбор существительных, контекстные подсказки.
- Контроль корректности формулировок: проверка на соответствие уровню таксономии, стоп-слова, семантическая корректность.
- Автоматическое грамматическое согласование (склонение) слов.
- Предварительный просмотр итогового текста в реальном времени.
- Экспорт результатов в форматы DOCX и TXT.
- Административная панель для управления базой знаний (справочники глаголов и существительных).
- Модуль машинного обучения для пакетной классификации новых глаголов.

## Целевая аудитория
Преподаватели, методисты, специалисты по проектированию образовательных программ.
